# helenomatos.com

My links page: portfolio, LinkedIn, GitHub, Instagram and Webgest in one place.

Plain HTML, CSS and a few lines of JavaScript. No frameworks, no build step, no dependencies.

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## Deploy

Hosted on Vercel. Security headers (CSP, HSTS, etc.) are set in `vercel.json`.

## Fonts

[Inter](https://github.com/rsms/inter) and [JetBrains Mono](https://github.com/JetBrains/JetBrainsMono) are self-hosted under the SIL Open Font License (see `fonts/`).
